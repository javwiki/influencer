# Dita Von Teese

## 简介

美国滑稽歌舞表演者、模特、服装设计师及作家，1972年出生于密歇根州。她以复兴经典滑稽歌舞表演美学而知名，舞台造型常借鉴20世纪中叶好莱坞与复古时尚。

## 职业经历

- 本名Heather Renée Sweet，青年时期学习古典芭蕾，并对历史服饰、内衣和复古电影形成兴趣。
- 20世纪90年代开始从事模特与滑稽歌舞表演，逐渐以精心设计的舞台服装和大型道具演出建立个人风格。
- 她的代表性演出包括“香槟杯”舞蹈，并曾在巴黎疯马秀等舞台亮相。
- 除巡演外，她还参与服装与美妆合作，并出版关于复古魅力和个人风格的书籍。

# 千歳吉野

## 简介

千歳吉野（ちとせ よしの，Chitose Yoshino），日本グラビアアイドル、アイドル、タレント、Coser。2000年1月8日出生于佐贺县，爱称「よしのん」。原鉄工所职员出身，曾为偶像团体「あまいものつめあわせ」成员。身高158cm、B100（K cup）的爆乳身材成为话题，在ヤングマガジン等杂志活跃，同时以 Cosplayer 身份活动。

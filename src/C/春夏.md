# 春夏

## 简介

中国大陆女演员、模特，本名李俊杰，1992年12月5日出生于云南昆明。出道前曾为多本中国大陆杂志及书籍拍摄封面，2015年凭电影《踏血寻梅》获得香港电影评论学会大奖最佳女演员及香港电影金像奖最佳女主角等奖项。

## 生涯概要

- 本名李俊杰，1992年12月5日出生于云南昆明，出道前曾为杂志、书籍担任封面模特及网店模特。
- 2014年出演电视剧《我心灿烂》入行，其后参演《岁月如金》《大好时光》等剧。
- 2015年凭电影处女作《踏血寻梅》获得香港电影评论学会大奖最佳女演员及香港电影金像奖最佳女主角，成为金像奖首位「90后」影后。
- 其后出演电影《晴雅集》（2020）、《风再起时》（2023）等。

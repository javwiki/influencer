# 春夏

## 简介

中国大陆女演员、模特，本名李俊杰，1992年12月5日出生于云南昆明。出道前曾为多本中国大陆杂志及书籍拍摄封面，2015年凭电影《踏血寻梅》获得香港电影评论学会大奖最佳女演员及香港电影金像奖最佳女主角等奖项。

# 陈雅婷

## 简介

中国女演员、平面模特。1991年出生于湖北武汉，毕业于湖北经济学院广告设计专业。被星探发掘后以平面模特身份入行，后转型为演员，曾用名陈雅婷，现以艺名「陈米麒」（JoJo Chen）活动。

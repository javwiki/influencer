# 陈雅婷

## 简介

中国女演员、平面模特。1991年8月31日出生于湖北武汉，毕业于湖北经济学院广告设计专业。被星探发掘后以平面模特身份入行，后转型为演员，曾用名陈雅婷，现以艺名「陈米麒」（JoJo Chen）活动。

## 生涯概要

- 1991年8月31日出生于湖北武汉，毕业于湖北经济学院广告设计专业，原名陈雅婷，现以艺名「陈米麒」活动。
- 在武汉街头被星探发掘，以平面模特身份入行，后转型演员。
- 2013年受邀出演潘文杰执导的古装剧《陆小凤与花满楼》；2015年主演古装剧《战国红颜之芈月传奇》。
- 2016年与陈小春合作主演网络剧《反黑》，并出演《恋爱方法论》。
- 2017年出演喜剧电影《欢乐喜剧人》，并参演张黎执导的古装玄幻剧《武动乾坤》。

# 曾之乔

## 简介

台湾演员、歌手及主持人，1988年出生于新竹县。她于青少年时期与刘品言组成女子组合Sweety进入演艺圈，之后持续参与电视剧、音乐及节目主持。

## 职业经历

- 2002年与刘品言组成Sweety，并于2003年发行首张专辑《嗨！Sweety》。
- 组合时期出演《紫禁之巅》《格斗天王》《爱情魔发师》等电视剧。
- 此后以个人身份继续从事戏剧、音乐和主持工作，出演《必娶女人》《后菜鸟的灿烂时代》等作品。
- 她也发行个人音乐作品，并参与电视及网络节目。

# 曾智希

## 简介

台湾女艺人，1989年12月20日出生于新北市，毕业于台北市立大学公共行政系。曾为伊林娱乐旗下模特儿（2018年5月合约到期），早年以艺名辛芭担任无双乐团舞者并加入「运彩甜心」团体，后任中天娱乐台《非常异视界》助理主持人、华视《名模出任务》固定班底，2017年出版写真集《SIMBA初见·曾智希》。

## 生涯概要

- 1989年12月20日出生于新北市，毕业于台北市立大学公共行政系。
- 曾为伊林娱乐旗下模特（2018年5月合约到期）；早年以艺名辛芭担任无双乐团舞者，并加入「运彩甜心」团体。
- 后任中天娱乐台《非常异视界》助理主持人、华视《名模出任务》固定班底。
- 2016、2017年先后出版《轻甜心》扑克牌、《限量女神桌历》及写真集《SIMBA初见·曾智希》。
- 2022年3月与交往六年的男友陈志强结婚。

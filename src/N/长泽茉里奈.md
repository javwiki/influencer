# 长泽茉里奈

## 简介

日本グラビアアイドル（写真偶像）、演员、艺人、プロ雀士（专业麻将选手）。1995年10月8日出生于埼玉县熊谷市。以童颜F杯罩的"合法ロリ巨乳"著称，爱称「まりちゅう」。元放課後プリンセス（放课后公主）成员（2013年加入，2014年因违规解雇，2016年一度复归，同年脱退退所）；2021年取得日本プロ麻雀協会职业麻雀牌手资格。妹妹为长泽圣爱。经ヴィズミック后现所属TRUSTAR。2025年7月以自身名义制作偶像团体Chuu♡Cute。

# Leng Yein

## 简介

Leng Yein（林云，1985年4月18日—），马来西亚 DJ、TikTok 创作者、演员、模特。出生于马来西亚，中文名林云；以 DJ 身份成名，后活跃于 TikTok（账号 @djlengyein，粉丝约 14.5 万，核验日期：2026-08-04）及 Facebook（官方页获赞逾 340 万，核验日期：2026-08-04），并担任 PADI 海洋环保亲善大使。曾获逾 20 项选美相关头衔，也出演过影视作品。原条目地区标注为柬埔寨，经核验应为马来西亚。

# Influencer 人物资料库

一个使用 mdBook 构建的中文人物资料索引。项目收录演员、模特、歌手、偶像、声优、内容创作者等公开人物的基础资料。

## 内容原则

- 只记录可由公开来源核实的信息，不根据相似用户名推断不同平台账号属于同一人。
- 人物的所属团体、经纪公司、粉丝数和平台状态等会变化的信息，应注明来源及核验日期。
- “地区”表示人物的来源地或通常认同的国家／地区，不表示其当前工作地点。
- 无可靠来源的条目应明确标记“待核验”，不得用模板化描述伪装为完整资料。
- 社交账号只能证明账号归属；出生信息、职业经历、奖项等事实应优先引用官方资料或可靠出版物。

详细要求见 [内容与来源规范](CONTENT_POLICY.md)。

## 资料状态

- `已核验`：关键身份信息具有可靠、可访问的对应来源。
- `部分核验`：仅部分信息或社交账号得到来源支持。
- `待核验`：尚缺少足够来源，不应视为确定事实。

`src/_meta/list.yaml` 中的完整度根据条目实际字段和来源自动计算，不代表人物知名度或内容质量。

## 本地构建

```bash
mdbook build
```

目录页、标签页和 `SUMMARY.md` 在部署时由 GitHub Action 与 `mdbook-summarizer` 自动生成。

# 李凯莉

## 简介

李凯莉（Kelly Lee），中国台湾女演员。因参演杨德昌执导的电影《一一》（2000，戛纳电影节首映）饰演吴念真的女儿而知名，该片为其主要作品；后毕业于美国康奈尔大学设计专业，返台开设设计事务所 KELLY LEE Design。

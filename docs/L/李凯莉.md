# 李凯莉

## 简介

李凯莉（Kelly Lee），中国台湾前演员，现为室内设计师。2000年在杨德昌执导的电影《一一》中饰演简婷婷（NJ 的女儿），该片于2000年戛纳电影节首映；此后未继续演员生涯，毕业于美国康奈尔大学室内设计专业，现于台北经营个人设计事务所。

## 职业经历

- 1999年参与杨德昌电影《一一》拍摄，饰演简婷婷。
- 2000年《一一》在戛纳电影节首映，并获戛纳最佳导演奖。
- 此后赴美国康奈尔大学学习室内设计，毕业后返台。
- 在台北经营个人室内设计事务所 KELLY LEE Design。

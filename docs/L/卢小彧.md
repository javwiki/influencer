# 卢小彧

## 简介

卢小彧（Pinklu，1986年1月1日—），中国内地女演员、模特。出生于上海市黄浦区，毕业于上海工程技术大学，经纪公司为上海佑星传媒；2011年起参加东方卫视《百里挑一》及上海卫视《今天我主持》等综艺节目，2016年主演《网红调教师》《嫩模集邮戳》《驯鬼为夫》等网络电影，2021年起转型为带货主播。

## 生涯概要

- 2011年6月参加上海卫视《今天我主持》，此前于同年4月至6月多次参加东方卫视《百里挑一》。
- 2015年6月参与录制腾讯视频《你正常吗》。
- 2016年主演《网红调教师》《嫩模集邮戳》；8月主演网络电影《驯鬼为夫》（饰齐晓晓）；随后主演惊悚悬疑片《诡影直播间》（饰催眠师小唯）。
- 2017年1月参加真人秀《女票炸了》，同年参演轻喜剧《丁丁小姐》。
- 2021年作为嘉宾参加《我不是财神》节目录制，同年起转型为带货主播。
- 2025年8月参演的电影《直播间爱情故事》上映。

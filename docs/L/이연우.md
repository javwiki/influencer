# 이연우

## 简介

韩国模特、网络主播。2000年出生于釜山，本名未公开。2021年首次参加 Miss Maxim Contest，在第一轮排名第2后因个人原因退赛；2023年再次参赛并获得亚军，因而被称为「연우히메」。2026年5月登上《Maxim》韩国版封面。

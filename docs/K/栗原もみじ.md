# 栗原もみじ

## 简介

栗原もみじ（くりばら もみじ，Kuribara Momiji，1996年9月29日—），日本写真偶像、模特、Cosplayer，埼玉县出身，身高165cm。演艺活动前从事服装行业，2022年前后以自由身参加摄影会起步，在摄影会现场被经纪公司相中后正式转向写真活动。2023年11月24日由竹书房发行1stイメージDVD《マロングラッセ》，实现映像出道；2024年5月起担任WELLPINE MOTORSPORT赛车女郎／大使，并参加全日本拉力锦标赛等赛事至2025年。2026年出演写真综艺《グラてん道場》，同年9月30日由竹书房发行1st纸质写真集《美尻の国》。

## 生涯概要

- **2022年前后** — 此前从事服装行业，之后以自由身参加摄影会等活动，开始模特工作；在摄影会期间被经纪公司邀请，正式展开写真活动。
- **2023年11月24日** — 竹书房发行1stイメージDVD《マロングラッセ》，实现映像出道。作品于2023年8月在冲绳县石垣岛拍摄，设定为饰演年长的前辈；2024年1月举办发行纪念活动。
- **2024年3月27日** — スパイスビジュアル发行2ndイメージDVD《ふわとろBODY》。
- **2024年5月** — 就任モータースポーツ车队「WELLPINE MOTORSPORT」赛车女郎，参与全日本拉力锦标赛等赛事，活动延续至2025年。
- **2024年7月20日** — ラインコミュニケーションズ发行3rdイメージDVD《もみじり》，饰演家庭教师等角色。
- **2024年10月25日** — エスデジタル发行4thイメージDVD《くりーみー》，以扎三股辫、戴黑框眼镜的女性自我打磨、逐渐改变为故事设定。
- **2025年5月23日** — 竹书房发行5thイメージDVD《くりもみちゃん》，收录与恋人相处的日常篇，以及以「レンタル彼女」身份造访观众家中的设定篇。
- **2025年9月** — ビビットキャスト配信デジタル写真集《甘く染まる時》（9月19日）与《紅くなるのは、これから》（9月26日），摄影均为杉吉ゆうじ。
- **2026年** — 出演写真综艺《グラてん道場》，与板野優花等人一同参与综艺企划。
- **2026年8月10日** — 集英社发行デジタル写真集《ありのままで》（週プレ PHOTO BOOK，摄影：笠井爾示）。
- **2026年9月30日** — 竹书房发行1st纸质写真集《美尻の国》（摄影：中山雅文）。

# 강인경

## 简介

韩国模特、网络主播。1997年7月29日出生于仁川松岛，2017年以 Artgravure 专属模特出道，曾多次登上《Maxim》韩国版封面（2020、2023、2025），后转型为 SOOP 主播。所属히로인 엔터테인먼트。

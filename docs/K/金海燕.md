# 金海燕

## 简介

金海燕（김해연，Kim Hae-yeon），韩国电影演员，1960年代活跃。韩国电影数据库（KMDB）收录其15部出演作品，包括《大沈清传》《燕山君》《脱线春香传》等。出生等个人资料未见公开记录。

## 职业经历

- 1960年出演《禁断之门》《脱线春香传》《我心中的那首歌》《卡秋莎》。
- 1961年出演《激流》《燕山君》。
- 1962年出演《大沈清传》《暴君燕山》《这世上的某处》《草笠童》。
- 1963年出演《东京悲歌》《爱情三百年》《天动》。
- 1966年出演《妖花》。
- KMDB 共收录其15部电影作品，角色包括成春香、仁淑母、神妃尚宫等。

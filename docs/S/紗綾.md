# 紗綾

## 简介

紗綾（さあや，Saaya），日本女演员、艺人及前写真偶像、歌手。1993年11月15日出生于福冈县北九州市。2005年小学5年级时以写真偶像出道，首张DVD《紗綾 さあや11歳》受到业界关注；同年作为舞蹈/声乐组合Sweet Kiss成员开展偶像活动，2006年改组为CHASE并以单曲《CHASE ME!》主流歌手出道。2018年底离开经纪公司后以自由身活动，以女演员为主业。

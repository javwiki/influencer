# 篠崎愛

## 简介

篠崎愛（しのざき あい，Shinozaki Ai），日本グラビアアイドル（写真偶像）、歌手、YouTuber、演员。1992年2月26日出生于东京都。2006年14岁以グラビア偶像出道，为女子中学生向杂志《Chu→Boh》看板娘；2007年获『週刊ヤングジャンプ』制コレGP準グランプリ，并凭剧集《24のひとみ》女優出道；2008年以单曲《M》歌手出道。女性偶像团体AeLL.成员（2011年加入），2015年起以个人歌手活动。2010年由マーブル转属シャイニングウィル，2018年12月退所，2020年与株式会社IMO业务提携。2016年登上韩版《MAXIM KOREA》封面（预约售罄，为同刊史上唯一），2020年获该刊「历代表纸ランキング」第1位。

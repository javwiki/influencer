# 보미

## 简介

韩国女歌手、偶像。本名정보미（Jeong Bomi），1996年5月12日出生。2016年起以舞蹈团队活动，2019年4月8日随女子组合 Girl Crush（现 STRAW）发行《Memories》出道，担任主舞与主 Rapper。

## 职业经历

- 2016年起以舞蹈团队形式参加活动，并登上《Crazy Giant》等杂志。
- 2018年与成员世希共同担任《Crazy Giant》12月号封面模特。
- 2019年4月8日随 Girl Crush 发行数字单曲《Memories》，正式以偶像身份出道。
- 2021年3月31日开设个人 YouTube 频道。
- 2023年发行单曲《오빠, 나 믿지?》，2024年发行《DRIVE》。

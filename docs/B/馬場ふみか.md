# 馬場ふみか

## 简介

馬場ふみか（ばば ふみか，Baba Fumika），日本女演员、写真平面模特及艺人。1995年6月21日出生于新潟县新潟市。2014年在读高中时以电影《パズル》演员出道，同年在《假面骑士Drive》中首次出演电视剧；2015年写真出道并成为杂志《non-no》专属模特，2023年自该志毕业；所属ネイムマネジメント（旧エリートジャパン）。

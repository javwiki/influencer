# 柳瀬さき

## 简介

日本グラビアアイドル（写真偶像）。1988年4月23日出生于千叶县。以100cm I杯罩的丰满身材著称，爱称「やなパイ」。旧艺名柳瀬早紀（读法相同）。曾属10-POINT、FORZA RECORD，现为フリーランス（自由身）活动。

## 生涯概要

- 1988年4月23日出生于千叶县，旧艺名柳瀬早纪，爱称「やなパイ」。
- 2014年7月以「柳瀬早纪」名义正式开展活动，参加汐留グラビア甲子园等赛事，同年晋级 ZAK THE QUEEN 决赛。
- 2015年首张 DVD《ミルキー・グラマー》发行并获 Amazon 偶像 DVD 榜第1位，随后发行写真集《blessing》。
- 2018年6月起活动休止约两年半（期间2020年10月31日前グラビア偶像身分休止），2020年11月签约 FORZA RECORD 并以「柳瀬さき」艺名复出。
- 2021年取得野菜ソムリエ（蔬菜品鉴师）资格；2022年1月与八福みずほ开设 YouTube 料理频道「となりの食卓」。
- 2025年起以自由身活动并创立品牌「pippin」；同年入选「グラドルDVDアワード TOP50」第8位。

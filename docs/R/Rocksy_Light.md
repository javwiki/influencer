# Rocksy Light

## 简介

Rocksy Light，本名 Alisa Bishop，俄罗斯 Cosplay 模特、Instagram 内容创作者。1992年6月28日出生于基洛夫，身高152 cm。以 Instagram 账号 @rocksylight（粉丝约32.7万）及 @alisapikapika 发布 Cosplay、生活及幕后内容，作品包括《进击的巨人》《英雄联盟》等角色；曾与 Bandai Namco 等品牌合作并出席俄罗斯漫展（Comic-Con Russia）。

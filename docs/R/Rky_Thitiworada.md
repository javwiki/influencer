# Rky Thitiworada

## 简介

Rky Thitiworada（ฐิติวรดา จังจริง），泰国模特、DJ、内容创作者。1999年3月16日出生于曼谷。以 TikTok 账号 @dj.rky（粉丝约3万，获赞约7.3万）、Instagram @rky_thitiworada 及 Facebook 页面「DJ Rky Thitiworada」发布 DJ 与模特内容。

## 职业经历

- 2017年前已开始模特工作，2017年以18岁之龄接受泰国媒体采访。
- 以 DJ 身份在曼谷及泰国各地演出，同时拍摄模特与写真作品。
- 在 TikTok、Instagram、Facebook 发布 DJ 演出与日常生活内容。
- 截至2026年10月，TikTok 约有3万关注者。

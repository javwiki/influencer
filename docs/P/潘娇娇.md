# 潘娇娇

## 简介

潘娇娇，中国平面模特、车模及艺人，又名潘思沁。2008年前后以车展模特出道，曾获2009年河北车展模特大赛最佳上镜奖与最佳人气奖、2009年内衣模特大赛河北赛区十佳、环球旅游皇后最佳上镜奖及十佳、世界旅游小姐华北赛区最佳上镜奖与全国十佳、2011年世界小姐天津赛区十佳。她也是推女郎签约模特、中国体育标准钢管舞联合总会会员、罗兰钢管舞蹈学校学员及第六届中国钢管舞锦标赛选手。出生年份在不同内容站存在1994年、2002年等互相矛盾的说法，暂不收录。

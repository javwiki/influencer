# 風吹ケイ

## 简介

日本グラビアアイドル（写真偶像）、演员、艺人。1999年4月5日出生于大阪府。身高167cm、J cup，以"逆三角形"腹肌身材著称。元客室乗務員（CA），コロナ禍工作减少后经由婚礼礼服模特进入演艺圈。现为女性偶像团体DЯAW♡ME成员，隶属事务所プライム。

## 活动

- **出道**：大阪的专门学校毕业后上京担任客室乗務員（CA）。コロナ禍中CA工作减少，开始做日结的婚礼礼服模特，经模特事务所邀请后不隶属事务所、以自由身份开始グラビア活动，首个工作是拍摄イメージビデオ。
- **グラビア**：2022年2月发行1st DVD《降臨》（スパイスビジュアル）。同年《週刊プレイボーイ》企划"次世代グラドルクビレ番付 2022年夏場所"当选"西之横纲"、"新世代グラドルボイン番付 2022年秋場所"当选"东之横纲"。以在"ミス呂布カルマオーディション"中的高评价为契机，此后多次出演《佐久間宣行のNOBROCK TV》。
- **获奖**：2022年12月获"グラビア・オブ・ザ・イヤー2022"大奖，同月获《週刊SPA!》"グラビアン魂アワード2022"リリー・フランキー赏；2024年12月获同奖项みうらじゅん个人奖"アート・ボディ赏"；2025年在DMM通贩销量榜为基础的"グラドルDVDアワード TOP50"中排名第1；2026年5月在"サマー・スタイル・アワード（SSA）2026"グラマラス部门获大奖，并同时获得粉丝投票决定的"推し選手賞"和特别奖"LEXXXY TOKYO 美バスト賞"。
- **写真与代言**：2023年5月发行1st写真集《幕開》（小学館）。同年11月起担任相模ゴム工業"サガミオリジナル"第15代宣传大使，任期一年。
- **DЯAW♡ME**：参加从YouTube频道《佐久間宣行のNOBROCK TV》诞生的限定偶像组合，2026年2月3日在パシフィコ横浜国立大ホール举行的"NOBROCK FES 2026 ～夢を語ったら叶っちゃった夜～"上正式亮相。

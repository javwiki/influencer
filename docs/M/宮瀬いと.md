# 宮瀬いと

## 简介

日本模特、演员。1999年1月4日出生于千叶县，2018年在第2届《JELLY》SHOWROOM 选秀中获得大奖，并从同年《JELLY》11月号起成为该杂志专属模特，2019年出演 ABEMA 恋爱真人秀《オオカミちゃんには騙されない》后关注度上升。所属 TWIN PLANET ENTERTAINMENT。

## 职业经历

- 2018年在第2届《JELLY》SHOWROOM 选秀中获得大奖，同年9月15日发售的《JELLY》11月号起成为专属模特。
- 2019年出演 ABEMA 恋爱真人秀《オオカミちゃんには騙されない》，节目播出后关注度显著上升。
- 出演《マツコ&有吉 かりそめ天国》《出川哲朗のアイ・アム・スタディー》《キニナル金曜日》等电视节目。
- 登上《LOVEggg》《JELLY》《JJ》等杂志，并参与富士フイルム、浅草愛和服等广告。
- 参加「デジタル超十代2018」「超十代-ULTRA TEENS FES-2019」「神戸コレクション2019 SPRING／SUMMER」等活动。

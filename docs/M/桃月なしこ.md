# 桃月なしこ

## 简介

桃月なしこ（ももつき なしこ，Momotsuki Nashiko），日本Cosplayer、模特、演员及YouTuber。1995年11月8日出生于爱知县丰桥市，另具准看护师资格。高中时经朋友介绍开始角色扮演活动，2017年出道；2019年演员出道，同年成为杂志《bis》常规模特；2020年出演《魔进战队煌辉者》淀娜一角受到关注，2022年开设YouTube频道，所属ゼロイチファミリア。

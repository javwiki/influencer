# 天木纯

## 简介

日本艺人、演员、元グラビアアイドル（写真偶像）。1995年10月16日出生于兵库县伊丹市，本名非公开。以I杯罩丰满身材著称，爱称「じゅんちゃん」。元仮面女子（假面女子）成员。姐姐为黑田绚子（元女演员）。经ワタナベエンターテインメント转入现所属エイジアプロモーション。丈夫为竞轮（競輪）选手佐々木悠葵（佐佐木悠葵）。
